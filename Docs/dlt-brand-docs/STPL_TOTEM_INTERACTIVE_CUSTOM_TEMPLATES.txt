TEMPLATE 1 — OTP login (Totem only — submit this first)
================================================================
Portal: Template → + New Template / Add Template

Template Name:          TOTEM_OTP_LOGIN
Communication Type:     SMS
Template Type:          Service Implicit
Template Category:      Communication/Broadcasting/Entertainment/IT
Content Type:           Text
Header / Sender ID:     TOTEMI
Brand Name:             Totem Interactive
Consent Template ID:    leave blank (not required for Service Implicit)
Upload Document:        optional — Totem GST / PE proof if the form asks

--- Copy/Paste Message (then select OTPCODE → + Add Variable) ---

Your verification code is OTPCODE. Valid for 10 minutes. Do not share this OTP with anyone.
- Totem Interactive

--- After variable is added, message must look like ---

Your verification code is {#var#}. Valid for 10 minutes. Do not share this OTP with anyone.
- Totem Interactive

Variable 1 tag:         Numeric / OTP / #numeric#  (whichever STPL lists)
Sample value:           482917
Variable count:         1

--- Sample Content (second box — real digits, no {#var#}) ---

Your verification code is 482917. Valid for 10 minutes. Do not share this OTP with anyone.
- Totem Interactive

Then Submit.

After status = Approved:
1. Copy the DLT Template ID from STPL.
2. In MSG91: bind this DLT template + header TOTEMI.
3. Put that MSG91 template id in MSG91_SMS_TEMPLATE_ID on the Reloved functions env.
